# Pitch decks

The two Erodoro Rips decks, as PDFs (viewable on GitHub) and as standalone HTML (open in a browser to see each slide's speaker notes).

- `rips-colosseum-plain.pdf` / `.html`: 10 slides in the plain, sentence-title style (Colosseum submission).
- `rips-editorial.pdf` / `.html`: 12 slides in the erodoro.xyz editorial look (competitors, roadmap, team).
- `rips-teaser.mp4`: a 15-second launch teaser (1080p) built with HyperFrames, with a produced 120 bpm score and sound design. A price line draws to +10% and "$1 of it earns 10¢". Then "what if $1 bought the move.", a tap on the rip button in a phone mockup, and a foil pack that bursts out, tears and lands on nvda upside. After that come the three-step mechanic, the stock in a box knocked aside by the upside arrow, and the erodoro end card. `video/` is the HyperFrames project that renders it.
- `landing.png`: the product screenshot both decks use.

Bracketed values like `[__]` are placeholders to fill with real numbers before presenting. The editable originals are Claude artifacts; these files are snapshots.
